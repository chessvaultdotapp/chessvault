This guide will help you get up and running with Chessvault.

## Installation

Chessvault currently offers development previews for **Linux x86_64** only. There are no stable releases yet.

Development previews may contain bugs or incomplete features.

### Linux

Download either package from the [GitHub releases page](https://github.com/chessvaultdotapp/chessvault/releases).

#### tarball

Download the Linux x86_64 `.tar.gz` archive and extract it to a folder of your choice. Then choose either option:

- **Run without installing:** Open a terminal in the extracted folder and run `./bin/chessvault`.
- **Install for your user:** Run `sh install-linux.sh` from the extracted folder. This installs Chessvault
  into `~/.local/bin` and adds a desktop launcher, without needing `sudo`. Launch it from your application
  menu or run `~/.local/bin/chessvault`.

#### Appimage

1. Download the Linux x86_64 `.AppImage` file.
2. Right-click the file, open its properties, and allow it to run as a program.
3. Open the AppImage to launch Chessvault.

### Other

Windows and macOS are not yet supported, but support is planned.
Mobile releases are not currently being considered.
