# Node.js

[Node.js](https://nodejs.org/en/download) runs [SVGO](svgo.md), our SVG optimizer.
It is only needed for artwork and documentation tooling, not to build, test,
or run Chessvault.

Install a supported LTS release using the official download instructions, then
verify the installation:

```console
$ node --version
v24.18.0
```

Example versions vary by installation. Next, install [pnpm](pnpm.md) to manage
the shared tooling dependencies.
