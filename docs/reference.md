# Documentation reference

## Shell commands

Commands prefixed with `$` should be run as a regular user, not root. The `$`
represents the shell prompt; do not type it.

For example (output varies with the installed version):

```console
$ cargo --version
cargo 1.98.0 (797e8a9bc 2026-08-05)
```

Type only `cargo --version` in your terminal, without `$` or `sudo`.
